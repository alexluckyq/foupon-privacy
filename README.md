# Foupon privacy policy

Shared privacy policy for the Foupon Android and iOS apps, published at
https://alexluckyq.github.io/foupon-privacy/.

`index.html` is a static page with no build step. Preview it in a browser before
publishing changes. Keep platform and app-version differences explicit, including
Android's legacy-session cleanup and iOS 2.800's ATT, advertising consent, province
notification targeting, and reduced location analytics. Historical-version
handling remains relevant while older apps and previously collected data exist.

The operator is Foupon Inc. and the privacy-contact email is support@foupon.com,
as confirmed by the app owner for the shared Android and iOS policy.
The policy does not set or verify provider/backend retention periods.

After publishing, update each store listing and each app's accessible Privacy
Policy link to the shared URL. Review App Store privacy labels and Google Play
Data safety answers separately against each app's actual behavior.
